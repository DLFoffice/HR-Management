# ระบบเงินสะสม 5% และเลื่อนเงินเดือน — วิธีติดตั้ง

หน้าเว็บ: `payroll.html` (แยกจากระบบบริหารงานบุคคล เข้าได้เฉพาะผู้มีรหัสผ่าน Admin)
ข้อมูลเงินเดือนเก็บใน **Google Sheet แยกใหม่** ที่พนักงานทั่วไปเข้าไม่ถึง

ถ้ายังไม่ได้ติดตั้ง หน้าเว็บจะทำงานใน **โหมดทดลอง** (ข้อมูลตัวอย่างในเบราว์เซอร์ รหัสผ่าน `demo1234`)

---

## 1. สร้าง Google Sheet และ Apps Script (ทำครั้งเดียว)

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `ระบบเงินเดือน (ข้อมูลลับ)` — **อย่าแชร์ให้พนักงาน**
2. เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิมทิ้ง แล้ววางเนื้อหาทั้งไฟล์ `payroll/Code.gs`
3. (แนะนำ) แก้บรรทัด `var INITIAL_ADMIN_PASSWORD = 'ChangeMe@2569';` เป็นรหัสผ่านของคุณ แล้วกดบันทึก
4. เลือกฟังก์ชัน `setupPayroll` ที่แถบด้านบน → กด **เรียกใช้** → อนุญาตสิทธิ์ทั้งหมด
   - ระบบจะสร้างแท็บ staff, contributions, rounds, roundItems, salaryHistory, logs
   - ตั้งรหัสผ่าน Admin และเปิดงานอัตโนมัติทุกวันเวลา 06:00 น.
5. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน** (จำเป็นเพื่อให้หน้าเว็บเรียกได้ — ข้อมูลถูกป้องกันด้วยรหัสผ่านที่ตรวจฝั่ง Google)
   - คัดลอก URL ที่ลงท้ายด้วย `/exec`

## 2. เชื่อมหน้าเว็บ

1. เปิด `payroll.html` → **ตั้งค่าการเชื่อมต่อ Google Apps Script** → วาง URL → **บันทึก URL**
2. เข้าสู่ระบบด้วยรหัสผ่านจากขั้นตอนที่ 1 → ระบบจะให้เปลี่ยนรหัสผ่านทันที (อย่างน้อย 8 ตัวอักษร)
3. หน้า **ตั้งค่า** → ใส่ **ID ของ Google Sheet ระบบบริหารงานบุคคล** (ส่วนระหว่าง `/d/` กับ `/edit` ใน URL) และอีเมลรับแจ้งเตือน → บันทึก
4. หน้า **เงินเดือนพนักงาน** → **ดึงรายชื่อจากระบบ HR** → แล้ว **นำเข้า Excel** เพื่อใส่เงินเดือน (กด "ดาวน์โหลดแม่แบบ Excel" เพื่อได้ไฟล์ที่มีรายชื่อครบ)

## 3. ระบบทำอะไรอัตโนมัติ (ทุกวัน 06:00 น.)

| เมื่อไร | ระบบทำอะไร |
|---|---|
| ทุกวันที่ 25 (ตั้งได้) | หักเงินสะสม 5% จากเงินเดือนล่าสุดของทุกคนที่ยังทำงาน — ไม่สร้างซ้ำถ้าหักเดือนนั้นแล้ว |
| 30 วันก่อน 1 เม.ย. / 1 ต.ค. | สร้างร่างรอบเลื่อนเงินเดือน ดึงคะแนน KPI (รอบที่ 1 ต.ค.–มี.ค. / รอบที่ 2 เม.ย.–ก.ย.) จากระบบ HR แล้วคำนวณ % ตามเกณฑ์ |
| ระหว่างร่าง | อัปเดตคะแนน KPI ที่เพิ่งกรอกให้ทุกวัน (รายการที่ผู้ดูแลแก้เองจะไม่ถูกทับ) |
| 1 เม.ย. / 1 ต.ค. | ถ้าทุกคนมี % ครบ → ปรับเงินเดือนและบันทึกประวัติ; ถ้ายังไม่ครบ → รอ และส่งอีเมลเตือนทุกวัน |
| ทุกครั้งที่มีงาน | ส่งอีเมลสรุปถึงอีเมลที่ตั้งไว้ |

กติกาเริ่มต้น (แก้ได้ในหน้าตั้งค่า):
- มีสิทธิ์เลื่อนเมื่อทำงานครบ **6 เดือน** ณ วันที่เลื่อน
- **เกณฑ์ % ของแต่ละระดับเว้นว่างไว้ให้กรอกเอง** (หน้าตั้งค่า → เกณฑ์ % ตามคะแนน KPI) ช่วงคะแนนตั้งไว้ตามเกรด KPI ในระบบ HR: 90+ ดีเยี่ยม, 80+ ดีมาก, 70+ ดี, 60+ พอใช้, ต่ำกว่า 60 ควรปรับปรุง — แก้/เพิ่ม/ลบระดับได้
- ระดับที่ยังไม่กรอก % หรือคนที่ยังไม่มีคะแนน KPI จะถือว่า "ยังไม่กำหนด %" — ระบบไม่ปรับเงินเดือนอัตโนมัติจนกว่าทุกคนจะมี % (กรอกตามระดับ หรือกรอกรายคนในตาราง)
- เงินที่เพิ่มปัดขึ้นเป็นหลักสิบบาท (แบบราชการ)
- วงเงินเลื่อนต่อรอบ 3% ของฐานเงินเดือน (ใช้เตือนเมื่อเกิน ไม่บังคับ)

## 4. รายงาน (PDF / Excel)

หน้า **ส่งออกรายงาน**: เงินสะสมประจำเดือน, สรุปรายปีงบประมาณ, ยอดคงเหลือรายบุคคล, ทะเบียนรายบุคคล, ผลการเลื่อนเงินเดือน, ทะเบียนเงินเดือน และ "Excel ทั้งหมด" (หลายชีตในไฟล์เดียว)
PDF เปิดเป็นหน้าตัวอย่างก่อนพิมพ์ → เลือก **Save as PDF**
